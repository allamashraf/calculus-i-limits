01Intuition

What is a limit?

\lim_{x \to a} f(x) = L

When x gets closer to a, f(x) gets closer to L.

A limit describes a trend, not an arrival. Take f(x) = x + 3 and move x toward 2: the two distances close together.

x 0.500 → 2
f(x) 3.500 → 5

|x - 2| = 1.500 |f(x) - 5| = 1.500

The closer x gets, the more digits it takes to see the difference.

03

Continuous change

Change that never jumps. Each of these settles toward a value it approaches but never quite reaches.

  • Temperature

    Tea cools toward the room: T(t) \to 22^\circ\mathrm{C}

  • Motion

    A spring settles to rest: x(t) \to 0

  • Growth

    A population nears its capacity: P(t) \to K

  • Signals

    Denser samples trace the wave: \Delta t \to 0

04Computer Science

Limits in computer science

In computing, the limit that matters most is n \to \infty: what happens as the input grows without bound.

Algorithm analysis

n\log_2 n versus n^2

Merge sort makes on the order of n\log_2 n comparisons. Comparing every pair of items takes on the order of n^2. The square is n^2; the teal strip inside it is n\log_2 n.

n doubles at every step, from 2 to 1,048,576
n8
n\log_2 n24
n^264
\dfrac{n\log_2 n}{n^2}0.375000

\lim_{n \to \infty} \frac{n \log n}{n^2} \;=\; \lim_{n \to \infty} \frac{\log n}{n} \;=\; 0

A limit of 0 means n\log n grows strictly slower than n^2: in asymptotic notation n\log n = o(n^2), and therefore also O(n^2). Big-O itself is defined by an inequality — f(n) \le c\,g(n) for all n \ge n_0 — not by a limit. The limit is a tool for comparing growth rates.

Numerical methods

Approximations that converge

Many algorithms cannot jump to an answer. They produce better and better approximations. Here x_{k+1} = \tfrac{1}{2}(x_k + 2), starting from x_1 = 3: every step halves the distance to 2.

    |x_k - 2| = \dfrac{1}{2^{\,k-1}} \;\longrightarrow\; 0

    Machine learning

    Training is a limit question

    Optimization algorithms repeatedly update parameters, w_{k+1} = w_k - \eta\,L'(w_k), lowering the loss a little each time. We study whether — and how fast — the process converges.

    05Theorems

    The limit laws

    Suppose \lim_{x\to a} f(x) = L and \lim_{x\to a} g(x) = M. Then limits respect arithmetic — every limit below is taken as x \to a.

    1. IConstant\lim c = c
    2. IIConstant multiple\lim\, c\,f(x) = c\,L
    3. IIISum\lim\, [f(x) + g(x)] = L + M
    4. IVDifference\lim\, [f(x) - g(x)] = L - M
    5. VProduct\lim\, f(x)\,g(x) = L\,M
    6. VIQuotient\lim \dfrac{f(x)}{g(x)} = \dfrac{L}{M}, \ \ M \neq 0
    7. VIIPower\lim\, [f(x)]^{n} = L^{n}, \ \ n \in \mathbb{Z}^{+}

    Worked example

    Use the Next step button or the right arrow key to reveal each step.

    \lim_{x \to 2}\, \bigl(3x^2 + 2x - 1\bigr)

    1. Step 1Sum and Difference laws III · IV

      = \lim_{x\to2} 3x^2 \;+\; \lim_{x\to2} 2x \;-\; \lim_{x\to2} 1

    2. Step 2Constant multiple, Power and Constant laws II · VII · I

      = 3\Bigl(\lim_{x\to2} x\Bigr)^{2} \;+\; 2\lim_{x\to2} x \;-\; 1

    3. Step 3Substitute \lim_{x\to2} x = 2

      = 3(2)^{2} + 2(2) - 1 \;=\; 12 + 4 - 1

    4. Result

      = 15

    06Advanced Optional

    Epsilon and delta

    “Closer” made precise. Someone challenges you with a tolerance \htmlClass{c-eps}{\varepsilon}; you must answer with a \htmlClass{c-del}{\delta}.

    For f(x) = 2x + 1, a = 2 and L = 5: |f(x) - 5| = |2x - 4| = 2\,|x - 2|. So whenever |x - 2| < \htmlClass{c-eps}{\varepsilon}/2, we get |f(x) - 5| < \htmlClass{c-eps}{\varepsilon}. The answer is \htmlClass{c-del}{\delta} = \htmlClass{c-eps}{\varepsilon}/2.

    1.00
    0.50

    |x - a| = 0.300

    |f(x) - L| = 0.600

    The precise definition of \lim_{x\to a} f(x) = L

    For every \htmlClass{c-eps}{\varepsilon} > 0 there exists \htmlClass{c-del}{\delta} > 0 such that

    0 < |x - a| < \htmlClass{c-del}{\delta} \quad\Longrightarrow\quad |f(x) - L| < \htmlClass{c-eps}{\varepsilon}

    The condition 0 < |x - a| leaves out x = a itself: the definition never looks at f(a). That is exactly why the hole in Chapter 02 did not matter.

    Optional proof

    The Sum Law

    If \lim_{x\to a} f(x) = L and \lim_{x\to a} g(x) = M, then

    \lim_{x \to a}\,\bigl[f(x) + g(x)\bigr] = L + M

    The key tool is the triangle inequality, |u + v| \le |u| + |v|: two small errors add up to at most their sum.

    Proof — let \htmlClass{c-eps}{\varepsilon} > 0

    Use the Next step button or the right arrow key to reveal each step.

    1. Use each limit with \htmlClass{c-eps}{\varepsilon}/2

      There is a \delta_1 > 0 with 0 < |x-a| < \delta_1 \Rightarrow |f(x) - L| < \tfrac{\varepsilon}{2}, and a \delta_2 > 0 with 0 < |x-a| < \delta_2 \Rightarrow |g(x) - M| < \tfrac{\varepsilon}{2}.

    2. Take the smaller distance

      Let \htmlClass{c-del}{\delta} = \min(\delta_1, \delta_2). If 0 < |x - a| < \htmlClass{c-del}{\delta}, both inequalities hold at once.

    3. Regroup the error

      \bigl|(f(x) + g(x)) - (L + M)\bigr| = \bigl|(f(x) - L) + (g(x) - M)\bigr|

    4. Triangle inequality

      \le |f(x) - L| + |g(x) - M| \;<\; \tfrac{\varepsilon}{2} + \tfrac{\varepsilon}{2} \;=\; \htmlClass{c-eps}{\varepsilon}

    5. Conclusion

      Every \htmlClass{c-eps}{\varepsilon} > 0 has a matching \htmlClass{c-del}{\delta} > 0, so \lim_{x\to a}[f(x) + g(x)] = L + M. ∎
